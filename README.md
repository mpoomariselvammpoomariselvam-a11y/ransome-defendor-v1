# Ransome Defender
Ransome Defender is a cybersecurity project designed to detect and identify potential ransomware threats using Machine Learning.
The system analyzes Windows executable files and classifies them as benign or ransomware based on extracted file features. It includes a Python FastAPI backend, a Machine Learning model, and a web-based frontend dashboard for scanning and monitoring. 
The project is developed as a defensive cybersecurity solution to improve ransomware awareness and detection.
